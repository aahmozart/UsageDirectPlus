
# usageDirect

This source builds the two apps "usageDirect" (`database` flavor) as well a "System usage stats" (`system` flavor).

### [Download usageDirect from F-Droid](https://f-droid.org/packages/godau.fynn.usagedirect)

For more information, please refer to the F-Droid description and screenshots.

### [Help translate](https://weblate.bubu1.eu/projects/usagedirect/)

This project can be translated through bubu's Weblate instance. It is recommended to use Weblate as it contains lots of
screenshots and further information to aid you with creating a high-quality translation.
